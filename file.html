1.2 Mission Objective[cite: 1]

This project specifies, trains, optimizes, and deploys a Hybrid AI/ML and Classical DSP Adaptive Noise Cancellation System[cite: 1]. The architecture cascades an unconstrained spatial/blind source separation front-end, a causal deep complex-domain neural speech enhancement engine, and a downstream classical adaptive filter (NLMS/FxLMS) to remove residual tonal stationary components[cite: 1].

The system operates across two functional modes:

  1. Uplink Speech Intelligibility Enhancement (Primary): Cleans the operator outbound voice from boom/throat microphones prior to radio transmission[cite: 1].
  2. Active Anti-Noise Generation (Downlink/Headphone ANC): Synthesizes phase-inverted acoustic waveforms to drive earphone transducers, suppressing ambient noise entering the ear canal[cite: 1].

Theoretical Signal Processing Foundations[cite: 1]

2.1 Mathematical Breakdown of Classical Adaptive Filtering[cite: 1]

In classical adaptive noise cancellation, an observed primary microphone signal d(n) captures target speech s(n) corrupted by additive noise v0(n):[cite: 1]

d(n) = s(n) + v0(n)

A secondary reference microphone captures noise x(n) correlated with v0(n) via acoustic transfer function H(z):[cite: 1]

v0(n) = h(n) * x(n) = Sum_{k=0}^{L-1} h(k) * x(n-k)

A classical FIR filter attempts to estimate H(z) dynamically:[cite: 1]

v_hat(n) = w_hat^T(n) * x(n)
e(n) = d(n) - v_hat(n)

Under NLMS, filter taps update via stochastic gradient:[cite: 1]

w_hat(n+1) = w_hat(n) + (mu / (||x(n)||^2 + epsilon)) * e(n) * x(n)

2.3 Rationale for Complex-Domain Deep Learning[cite: 1]

Deep neural networks solve these limitations by framing noise suppression as a non-linear spectral mapping and complex-domain filtering problem[cite: 1]. Human speech formants follow strict physiological, temporal, and harmonic constraints governed by vocal tract dynamics[cite: 1].

By utilizing Complex STFT, neural architectures model both spectral magnitude envelopes and phase continuity:[cite: 1]

Y(k, t) = S(k, t) + N(k, t) = |Y(k,t)| * e^(j * theta_Y(k,t))

Phase modeling is essential for low-SNR environments (SNR < 0 dB)[cite: 1]. Traditional magnitude-only masking synthesizes time-domain signals using corrupted input phase, creating audible musical noise[cite: 1]. Complex Ratio Masking (CRM) preserves acoustic phase coherence:[cite: 1]

S_hat(k,t) = M_complex(k,t) * Y(k,t) = (M_r + j*M_i) * (Y_r + j*Y_i)
S_hat_r = M_r*Y_r - M_i*Y_i
S_hat_i = M_r*Y_i + M_i*Y_r

Operating directly on complex coefficients using CRM or Deep Complex Filtering prevents speech distortion and phase smearing in low-SNR environments (down to -15 dB)[cite: 1].

2.4 Convergence Analysis of Adaptive Filters[cite: 1]

The convergence behavior of NLMS is governed by the eigenvalue spread of the input signal autocorrelation matrix R = E[x(n)x^T(n)][cite: 1]. For colored noise sources common in defense environments (helicopter rotors, engine rumble), the condition number kappa(R) = lambda_max/lambda_min can exceed 1000, causing:[cite: 1]

  1. Slow convergence in directions corresponding to small eigenvalues (low-frequency tonal components)[cite: 1]
  2. Misadjustment proportional to mu * trace(R), requiring careful step-size selection[cite: 1]
  3. Divergence risk when impulse noise violates the persistent excitation assumption[cite: 1]

The optimal step size mu_opt = 2/(lambda_max + lambda_min) yields convergence time constant tau = 1/(2*mu*lambda_min)[cite: 1]. For a 64-tap filter at 16 kHz with vehicle noise (kappa ~ 500), this requires ~32,000 samples (2 seconds) to converge — far too slow for tactical onset transients[cite: 1].

2.5 Wiener Filter Optimum and Its Limitations[cite: 1]

The Wiener solution represents the statistically optimal linear filter:[cite: 1]

w_opt = R^{-1} * p
where R = E[x(n)x^T(n)] and p = E[x(n)*d(n)]

In stationary conditions, NLMS converges toward w_opt[cite: 1]. However, defense acoustics violate the wide-sense stationary (WSS) assumption within 50-200 ms during ballistic events[cite: 1]. The autocorrelation matrix R becomes time-varying: R(n) = lambda*R(n-1) + (1-lambda)*x(n)x^T(n) with forgetting factor lambda ~ 0.99[cite: 1]. Even exponential forgetting cannot track rapid spectral changes during muzzle blasts where the noise power spectral density shifts by 30+ dB within 1 ms[cite: 1].

This fundamental limitation motivates the hybrid architecture: a neural network handles the non-stationary, non-linear components that classical adaptive filtering cannot track, while the downstream NLMS operates only on the residual stationary tones remaining after neural enhancement — conditions where classical optimality theory holds[cite: 1].

3.2 GTCRN — Primary Tactical Recommendation[cite: 1]

GTCRN resolves the trade-off between computational complexity and separation performance on embedded platforms using three complementary techniques:[cite: 1]

  1. ERB Subband Compression: Compresses 257 linear STFT bins to B=64 ERB bands matching human auditory resolution, shifting computation to vocal formants below 4 kHz[cite: 1].
  2. Grouped Convolutions + DPGRNN: Splits features into G=4 disjoint channel groups, processing independently before cross-group shuffling[cite: 1]. Intra-frame RNN captures spectral envelopes; inter-frame RNN captures temporal continuity[cite: 1].
  3. Temporal Recurrent Attention (TRA): Zero-lookahead attention identifies transient energy surges (muzzle blasts, artillery) and suppresses network activations, preventing impulsive smearing without degrading speech consonants[cite: 1].

3.3 DeepFilterNet3 — Wideband High-Fidelity Alternative[cite: 1]

DeepFilterNet performs enhancement at full-band 48 kHz[cite: 1]. Stage 1 predicts ERB gains; Stage 2 reconstructs fine harmonic structures via deep complex filtering with a 5-tap causal frame window:[cite: 1]

S_hat(f, t) = Sum_{l=0}^{4} W*(f, t, l) * Y(f, t-l)

Limitation: 2-frame lookahead (20 ms) + physical I2S buffering (16-24 ms) pushes total latency close to the 40 ms tactical boundary[cite: 1].

3.4 DTLN — Robust Baseline[cite: 1]

DTLN processes through two cascaded stages: (1) log-magnitude STFT mask prediction coupled with noisy phase; (2) learned 1D autoencoder for non-linear phase repair[cite: 1]. Simple and robust, but shows transient smearing during intense small-arms fire[cite: 1].

4.1 Stage Functional Descriptions[cite: 1]

  5. Stage 5 — NLMS Residual: Lightweight classical filter (order M=32-64) downstream of neural network tracks remaining linear stationary tones[cite: 1]. Upstream neural processing ensures NLMS operates within its linear stability envelope[cite: 1].
  6. Stage 6 — Output Limiter: Normalizes dynamic range and prevents numeric wraparound clipping during acoustic surges[cite: 1].

4.3 Auxiliary-Function IVA Mathematical Formulation[cite: 1]

Aux-IVA separates B sources from M=2 microphone observations in the frequency domain[cite: 1]. For each frequency bin f:[cite: 1]

Y(f, t) = A(f) * S(f, t)    [M x B mixing model]
W(f) = A^{-1}(f)             [demixing matrix]
X(f, t) = W(f) * Y(f, t)     [separated sources]

The auxiliary function update rule for the demixing matrix:[cite: 1]

W_new(f) = W(f) - mu * (phi(X) * X^H - I) * W(f)

where:
  phi(X) = E[|X|^(-2)] * diag(Expected source powers)
  mu = step size (0.01-0.1)
  H = conjugate transpose
  I = identity matrix

Convergence typically requires 10-20 iterations per frequency bin[cite: 1]. With G=4 frequency groups processed in parallel, total Aux-IVA latency is ~0.3 ms on Cortex-A76[cite: 1].

4.4 Transient Ballistic Onset Gate Logic[cite: 1]

The gate operates on the spectral flux derivative of the primary microphone signal:[cite: 1]

SF(t) = Sum_k | |X(k,t)| - |X(k,t-1)| |    [spectral flux]
DSF(t) = SF(t) - SF(t-1)                    [derivative]

Gate state machine:
  if DSF(t) > threshold_adaptive:
      gate_state = CLOSED (attenuate by 20 dB)
      recovery_counter = 0
  elif gate_state == CLOSED:
      recovery_counter += 1
      attenuation = 20 * exp(-recovery_counter / tau_ms)
      if attenuation < 0.5 dB: gate_state = OPEN

threshold_adaptive = median(SF(t-100:t)) * 3.0
tau_ms = 5.0    [5 ms exponential recovery]

4.5 NLMS Residual Filter Configuration[cite: 1]

The downstream NLMS filter operates on the neural-enhanced signal with the secondary reference microphone as its noise reference:[cite: 1]

Filter order M = 64 (4 ms memory @ 16 kHz)
Step size mu = 0.05 (conservative for stability)
Regularization epsilon = 1e-6
Forgetting factor (optional): lambda = 0.9995

Update rule:
w(n+1) = w(n) + (mu / (x^T*x + eps)) * e(n) * x(n)

where:

                       materials=pra.Material(0.20), max_order=6)

        room.add_source([4.0, 0.5, 1.8], signal=buf)

    sf.write(f"{output_dir}/{base}_clean.wav", gt.astype(np.float32), fs)

6.4 Loss Implementation[cite: 1]

class CompositeTacticalLoss(nn.Module):
    def __init__(self, alpha=0.5, lt=0.2, ls=0.8):
        super().__init__()
        self.alpha, self.lt, self.ls, self.eps = alpha, lt, ls, 1e-8

    def forward(self, est_wav, tgt_wav, est_spec, tgt_spec):
        # SI-SDR
        dot = torch.sum(est_wav * tgt_wav, dim=-1, keepdim=True)
        s_tgt = (dot / (torch.sum(tgt_wav**2, dim=-1, keepdim=True) + self.eps)) * tgt_wav
        e_noise = est_wav - s_tgt
        si_sdr = 10 * torch.log10(torch.sum(s_tgt**2) / (torch.sum(e_noise**2) + self.eps))
        loss_time = -torch.mean(si_sdr)

        # Power-compressed magnitude + RI
        m_est = torch.abs(est_spec).clamp(min=self.eps) ** self.alpha
        m_tgt = torch.abs(tgt_spec).clamp(min=self.eps) ** self.alpha
        loss_mag = torch.mean((m_est - m_tgt)**2)
        r_est = m_est * torch.cos(torch.angle(est_spec))
        i_est = m_est * torch.sin(torch.angle(est_spec))
        r_tgt = m_tgt * torch.cos(torch.angle(tgt_spec))
        i_tgt = m_tgt * torch.sin(torch.angle(tgt_spec))
        loss_ri = torch.mean((r_est-r_tgt)**2 + (i_est-i_tgt)**2)

        return self.lt * loss_time + self.ls * (loss_mag + loss_ri)

6.6 Dual-Path Grouped RNN Architecture[cite: 1]

The DPGRNN module is the computational core of GTCRN, processing features through two complementary recurrent pathways:[cite: 1]

Intra-frame RNN (Spectral Domain):
    Input: x[t] = [B, T, C//G] per group G
    GRU hidden states capture spectral envelope correlations
    Across ERB bands within each time frame
    Captures formant structure, harmonic relationships

Inter-frame RNN (Temporal Domain):
    Input: y[t] = concat(group_0[t], ..., group_G-1[t])
    GRU hidden states capture temporal continuity
    Across time frames within each frequency group
    Captures speech dynamics, pitch contours, voicing

Group Shuffle (Cross-Group Communication):
    After every 2 intra+inter RNN blocks, features are
    reshuffled across groups to prevent information isolation
    Shuffle pattern: [g0,g1,g2,g3] -> [g1,g0,g3,g2]

The grouped architecture reduces parameter count by G=4x compared to full-band RNN processing, while the shuffle operation maintains cross-frequency information flow[cite: 1]. This achieves 94% of full-band performance at 25% of the computational cost[cite: 1].

SAMPLE_RATE, FRAME_LEN, HOP_LEN = 16000, 512, 128
BLOCK_SIZE = HOP_LEN  # 8ms

audio_in_q = queue.Queue(maxsize=16)
audio_out_q = queue.Queue(maxsize=16)
window = np.sqrt(np.hanning(FRAME_LEN)).astype(np.float32)
in_buf = np.zeros(FRAME_LEN, dtype=np.float32)
out_buf = np.zeros(FRAME_LEN, dtype=np.float32)

opts.intra_op_num_threads = 2
opts.execution_mode = ort.ExecutionMode.ORT_SEQUENTIAL
sess = ort.InferenceSession("gtcrn_streaming.onnx", opts,
    providers=['CUDAExecutionProvider', 'CPUExecutionProvider'])

conv_state = np.zeros((2, 1, 16, 65), dtype=np.float32)
rnn_state = np.zeros((2, 1, 16, 64), dtype=np.float32)

def audio_cb(indata, outdata, frames, time, status):
    if status: print(f"[WARN] {status}", file=sys.stderr)
    audio_in_q.put_nowait(indata[:, 0].copy())
    try: outdata[:, 0] = audio_out_q.get_nowait()
    except queue.Empty: outdata.fill(0.0)

with sd.Stream(channels=2, samplerate=SAMPLE_RATE, blocksize=BLOCK_SIZE,
               callback=audio_cb, latency='low'):
    while True:
        try:
            samples = audio_in_q.get(timeout=1.0)
            in_buf[:-BLOCK_SIZE] = in_buf[BLOCK_SIZE:]
            in_buf[-BLOCK_SIZE:] = samples

            windowed = in_buf * window
            spectrum = np.fft.rfft(windowed, n=FRAME_LEN)
            r_in = np.real(spectrum).astype(np.float32).reshape(1,1,-1)
            i_in = np.imag(spectrum).astype(np.float32).reshape(1,1,-1)

            r_out, i_out, conv_state, rnn_state = sess.run(None, {
                "input_real": r_in, "input_imag": i_in,
                "in_conv_state": conv_state, "in_rnn_state": rnn_state})

            enhanced = (r_out[0,0,:] + 1j*i_out[0,0,:]).astype(np.complex64)
            time_synth = np.fft.irfft(enhanced, n=FRAME_LEN) * window

            out_buf += time_synth
            frame = np.clip(out_buf[:BLOCK_SIZE], -0.98, 0.98)
            out_buf[:-BLOCK_SIZE] = out_buf[BLOCK_SIZE:]
            out_buf[-BLOCK_SIZE:] = 0.0
            audio_out_q.put(frame)
        except queue.Empty: continue
        except KeyboardInterrupt: break

7.3 Hybrid NLMS Residual Filter[cite: 1]

class HybridNLMSResidualFilter:
    """NLMS filter for residual tonal noise suppression downstream of neural net."""
    def __init__(self, order=64, mu=0.05, eps=1e-6):
        self.order, self.mu, self.eps = order, mu, eps
        self.weights = np.zeros(order, dtype=np.float32)
        self.ref_buf = np.zeros(order, dtype=np.float32)

    def process_sample(self, enhanced_sample, ref_noise_sample):
        self.ref_buf[1:] = self.ref_buf[:-1]
        self.ref_buf[0] = ref_noise_sample
        predicted = np.dot(self.weights, self.ref_buf)
        clean = enhanced_sample - predicted
        ref_energy = np.dot(self.ref_buf, self.ref_buf) + self.eps
        self.weights += (self.mu / ref_energy) * clean * self.ref_buf
        return clean

#!/usr/bin/env python3
"""EMBEDDED RPi5 REAL-TIME DAEMON (INT8 ONNX, pinned to Core 3)"""
import numpy as np, alsaaudio, onnxruntime as ort, os, sys

os.sched_setaffinity(0, {3})  # Pin to isolated Core 3
os.system("chrt -f -p 90 %d" % os.getpid())  # SCHED_FIFO priority 90

FS, PERIOD, FRAME = 16000, 128, 512
WINDOW = np.sqrt(np.hanning(FRAME)).astype(np.float32)

inp = alsaaudio.PCM(alsaaudio.PCM_CAPTURE, alsaaudio.PCM_NORMAL,
    channels=2, rate=FS, format=alsaaudio.PCM_FORMAT_S16_LE,
    periodsize=PERIOD, device="hw:seeed2micvoicec,0")
out = alsaaudio.PCM(alsaaudio.PCM_PLAYBACK, alsaaudio.PCM_NORMAL,
    channels=2, rate=FS, format=alsaaudio.PCM_FORMAT_S16_LE,
    periodsize=PERIOD, device="hw:seeed2micvoicec,0")

opts = ort.SessionOptions()
opts.intra_op_num_threads = 1  # Strict single-thread on Core 3
opts.execution_mode = ort.ExecutionMode.ORT_SEQUENTIAL
sess = ort.InferenceSession("gtcrn_int8.onnx", opts,
    providers=['CPUExecutionProvider'])

in_ring = np.zeros(FRAME, dtype=np.float32)
out_ring = np.zeros(FRAME, dtype=np.float32)
conv_st = np.zeros((2,1,16,65), dtype=np.float32)
rnn_st = np.zeros((2,1,16,64), dtype=np.float32)

while True:
    try:
        length, raw = inp.read()
        if length <= 0: continue
        pcm = np.frombuffer(raw, dtype=np.int16)
        primary = pcm[0::2].astype(np.float32) / 32768.0

        in_ring[:-PERIOD] = in_ring[PERIOD:]
        in_ring[-PERIOD:] = primary

        windowed = in_ring * WINDOW
        fft_d = np.fft.rfft(windowed, n=FRAME)
        r_in = np.real(fft_d).astype(np.float32).reshape(1,1,-1)
        i_in = np.imag(fft_d).astype(np.float32).reshape(1,1,-1)

        r_o, i_o, conv_st, rnn_st = sess.run(None, {
            "input_real": r_in, "input_imag": i_in,
            "in_conv_state": conv_st, "in_rnn_state": rnn_st})

        enhanced = (r_o[0,0,:] + 1j*i_o[0,0,:]).astype(np.complex64)
        synth = np.fft.irfft(enhanced, n=FRAME) * WINDOW
        out_ring += synth
        block = np.clip(out_ring[:PERIOD], -0.99, 0.99)
        out_ring[:-PERIOD] = out_ring[PERIOD:]
        out_ring[-PERIOD:] = 0.0

        out_s16 = (block * 32767).astype(np.int16)
        stereo = np.column_stack((out_s16, out_s16)).flatten().tobytes()
        out.write(stereo)
    except KeyboardInterrupt: break
    except Exception as e: print(f"[ERROR] {e}", file=sys.stderr)

9.2 Latency Component Deep Dive[cite: 1]

ADC Capture (4.0 ms on RPi5): The I2S DMA controller transfers 64-sample blocks (4 ms at 16 kHz) directly to memory without CPU involvement[cite: 1]. The BCM2712's DMA engine operates asynchronously, filling ring buffers while the CPU processes the previous block[cite: 1]. This overlap eliminates capture-induced stalls[cite: 1].

STFT + ERB (0.85 ms): The 512-point real FFT uses ARM NEON-accelerated radix-2 Cooley-Tukey decomposition[cite: 1]. The ERB compression matrix (64x257) is precomputed and applied as a single GEMV operation via NEON SDOT, completing in ~0.3 ms for the magnitude computation[cite: 1].

Neural Inference (1.22 ms): GTCRN processes one 512-sample frame through 4 grouped conv layers, 2 intra-frame GRU blocks, 2 inter-frame GRU blocks, and the TRA attention module[cite: 1]. The entire forward pass executes on a single Cortex-A76 core with INT8 weights, staying well within the 8 ms hop budget[cite: 1].

Determinism Guarantee: With PREEMPT_RT + Core 3 isolation, kernel jitter drops from 1.5 ms (generic Linux) to 0.2 ms (99th percentile)[cite: 1]. The worst-case E2E latency of 17.22 ms includes 3x standard deviation headroom above the mean 11.42 ms[cite: 1].

#!/usr/bin/env python3
"""AUTOMATED PERFORMANCE VALIDATION TEST HARNESS"""
import numpy as np, soundfile as sf
from pesq import pesq
from pystoi import stoi
import sys

def evaluate(clean_path, noisy_path, enhanced_path):
    clean, fs = sf.read(clean_path)
    noisy, _ = sf.read(noisy_path)
    enhanced, _ = sf.read(enhanced_path)
    assert fs == 16000, "All streams must be 16kHz"

    min_len = min(len(clean), len(noisy), len(enhanced))
    clean, noisy, enhanced = clean[:min_len], noisy[:min_len], enhanced[:min_len]

    pesq_noisy = pesq(fs, clean, noisy, 'wb')
    pesq_enh = pesq(fs, clean, enhanced, 'wb')
    stoi_noisy = stoi(clean, noisy, fs)
    stoi_enh = stoi(clean, enhanced, fs)

    def sisdr(ref, est):
        e = 1e-8
        sc = np.dot(est, ref) / (np.sum(ref**2) + e)
        return 10*np.log10((np.sum((sc*ref)**2)+e)/(np.sum((est-sc*ref)**2)+e))

    dsnr = sisdr(clean, enhanced) - sisdr(clean, noisy)

    print(f"PESQ:  {pesq_noisy:.2f} -> {pesq_enh:.2f}  (target >2.50) {'PASS' if pesq_enh>=2.50 else 'FAIL'}")
    print(f"STOI:  {stoi_noisy:.2f} -> {stoi_enh:.2f}  (target >0.85) {'PASS' if stoi_enh>=0.85 else 'FAIL'}")
    print(f"dSNR:  {dsnr:.2f}dB       (target >15dB) {'PASS' if dsnr>=15 else 'FAIL'}")

if __name__ == "__main__":
    if len(sys.argv) < 4:
        print("Usage: python eval.py <clean> <noisy> <enhanced>")
        sys.exit(1)
    evaluate(sys.argv[1], sys.argv[2], sys.argv[3])

Definitive Architectural Synthesis[cite: 1]

The combination of an unconstrained blind source separation front-end (Aux-IVA), an ultra-low-complexity complex-domain neural backbone (GTCRN), and a classical downstream adaptive stage (NLMS) addresses the physical limitations of legacy ANC in defense environments[cite: 1].

  1. ERB Compression halves computational load while preserving critical vocal formants below 4 kHz[cite: 1].
  2. Complex Domain (CRM) preserves acoustic phase relationships, preventing speech distortion in low-SNR environments (down to -15 dB)[cite: 1].
  3. Temporal Recurrent Attention (TRA) identifies transient ballistic energy spikes, attenuating muzzle blasts without destabilizing recurrent states[cite: 1].
  4. Classical NLMS Downstream focuses exclusively on removing residual stationary tones from the stabilized neural output[cite: 1].
  5. RPi 5 Deployment: CPU Core 3 isolation (isolcpus=3), PREEMPT_RT, and direct I2S DMA achieve deterministic 17.22 ms roundtrip latency at RTF 0.152, drawing under 5W[cite: 1].
Summary: This architecture achieves >15 dB SNR improvement, >0.85 STOI, >2.50 PESQ, and <17.22 ms latency on a Raspberry Pi 5 while consuming under 7.5W — meeting all DRDO tactical communication requirements for adaptive noise cancellation in defence environments[cite: 1].

A.1 GTCRN Model Definition (PyTorch)[cite: 1]

class GTCRN(nn.Module):
    """Grouped Temporal Convolutional Recurrent Network for tactical ANC."""
    def __init__(self, n_fft=512, hop=128, n_erb=64, n_groups=4, hidden=64):
        super().__init__()
        self.n_fft, self.hop, self.n_erb = n_fft, hop, n_erb
        freq_bins = n_fft // 2 + 1

        # ERB compression matrix
        self.erb_W = nn.Parameter(torch.randn(n_erb, freq_bins) * 0.01)

        # Grouped convolutional encoder
        self.encoder = nn.ModuleList([
            nn.Conv1d(2 * n_erb, hidden * n_groups, 3,
                      padding=1, groups=n_groups),
            nn.GroupNorm(n_groups, hidden * n_groups),
            nn.PReLU(),
            nn.Conv1d(hidden * n_groups, hidden * n_groups, 3,
                      padding=1, groups=n_groups),
            nn.GroupNorm(n_groups, hidden * n_groups),
            nn.PReLU(),
        ])

        # Dual-path grouped RNN
        self.intra_rnn = nn.GRU(hidden, hidden, batch_first=True)
        self.inter_rnn = nn.GRU(hidden, hidden, batch_first=True)

        # Temporal Recurrent Attention
        self.tra_query = nn.Linear(hidden, hidden)
        self.tra_key = nn.Linear(hidden, hidden)
        self.tra_value = nn.Linear(hidden, hidden)

        # Complex mask decoder
        self.decoder = nn.Sequential(
            nn.Linear(hidden, hidden * 2), nn.PReLU(),
            nn.Linear(hidden * 2, freq_bins * 2))

    def forward(self, real, imag, conv_state=None, rnn_state=None):
        # ERB compression
        mag = torch.sqrt(real**2 + imag**2 + 1e-8)
        erb = torch.matmul(self.erb_W, mag)  # [B, n_erb, T]

        # Stack real/imag ERB features
        x = torch.cat([erb, erb], dim=1)  # placeholder for complex ERB

        # Grouped convolutions
        for layer in self.encoder:
            x = layer(x) if not isinstance(layer, (nn.GroupNorm, nn.PReLU)) else layer(x)

        # Dual-path RNN
        B, C, T = x.shape
        x = x.permute(0, 2, 1)  # [B, T, C]
        x, _ = self.intra_rnn(x)
        x, _ = self.inter_rnn(x)

        # TRA attention (zero lookahead)
        Q = self.tra_query(x)
        K = self.tra_key(x)
        V = self.tra_value(x)
        attn = torch.softmax(torch.bmm(Q, K.transpose(1,2)) / (C**0.5), dim=-1)
        x = x + torch.bmm(attn, V)

        # Complex mask
        mask = torch.sigmoid(self.decoder(x))
        Mr = mask[..., :self.n_fft//2+1]
        Mi = mask[..., self.n_fft//2+1:]

        # Apply CRM
        out_r = real * Mr - imag * Mi
        out_i = real * Mi + imag * Mr
        return out_r, out_i

  2. Measure everything: Log metrics from day one; never guess about performance[cite: 1].
  3. PC first, RPi second: Validate quality on PC before optimizing for edge[cite: 1].
  4. Hybrid wins: AI + classical always outperforms pure approaches[cite: 1].
  5. I2S over USB: Direct I2S DMA eliminates USB packetization jitter[cite: 1].
  6. Core isolation: PREEMPT_RT + isolcpus=3 for deterministic timing[cite: 1].
  7. Complex domain: CRM preserves phase; magnitude-only loses intelligibility at low SNR[cite: 1].

D.1 ONNX Runtime Dynamic Quantization[cite: 1]

Dynamic quantization converts FP32 weights to INT8 at runtime, preserving accuracy while reducing model size by 4x:[cite: 1]

#!/usr/bin/env python3
"""INT8 DYNAMIC QUANTIZATION FOR ONNX RUNTIME"""
import onnxruntime as ort
from onnxruntime.quantization import quantize_dynamic, QuantType

# Load FP32 ONNX model
model_path = "gtcrn_streaming.onnx"
quant_path = "gtcrn_int8.onnx"

# Dynamic quantization (weight-only, activations remain FP32)
quantize_dynamic(
    model_input=model_path,
    model_output=quant_path,
    weight_type=QuantType.QInt8,
    per_channel=True,
    reduce_range=False,
)

# Verify size reduction
import os
fp32_size = os.path.getsize(model_path) / 1024
int8_size = os.path.getsize(quant_path) / 1024
print(f"FP32: {fp32_size:.0f} KB -> INT8: {int8_size:.0f} KB ({int8_size/fp32_size*100:.0f}%)")

# Benchmark inference speed
import numpy as np, time
dummy_r = np.random.randn(1, 1, 257).astype(np.float32)
dummy_i = np.random.randn(1, 1, 257).astype(np.float32)
dummy_cs = np.zeros((2, 1, 16, 65), dtype=np.float32)
dummy_rs = np.zeros((2, 1, 16, 64), dtype=np.float32)

sess = ort.InferenceSession(quant_path, providers=['CPUExecutionProvider'])
inputs = {"input_real": dummy_r, "input_imag": dummy_i,
          "in_conv_state": dummy_cs, "in_rnn_state": dummy_rs}

# Warmup
for _ in range(10): sess.run(None, inputs)

# Benchmark
times = []
for _ in range(1000):
    t0 = time.perf_counter()
    sess.run(None, inputs)
    times.append((time.perf_counter() - t0) * 1000)

print(f"Mean latency: {np.mean(times):.3f} ms")
print(f"P99 latency:  {np.percentile(times, 99):.3f} ms")
print(f"RTF: {np.mean(times)/8.0:.4f} (target < 0.15)")
